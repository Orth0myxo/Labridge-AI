# Labridge AI
Labridge AI is an AI-powered laboratory assistant designed to help patients better understand their laboratory test results.

## features
- Generates patients-friendly explanations of laboratory results.
- Supports multiple languages.
- Stores and processes results using Google sheets.
- Built with Google Apps Script.
  
  ## Project Vision
  The goal of Labridge AI is to bridge the communication gap between laboratory professionals and patients by making laboratory reports easier to understand while supporting multilingual healthcare communication.

  ## Future Plans
  - Hospital integration
  - Voice support
  - More AI-powered health insight
